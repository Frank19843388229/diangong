## 一、图片规格（统一，不然画面会很乱）

- 格式：**PNG-24，透明背景**（实物图；安全标识可用 SVG/PNG）
- 尺寸：**512×512 px**（货架格子 86×52，512 足够）
- 构图：物体居中占 80%~85%，四周留 8%~10% 透明边
- 视角：统一 **45° 俯视 / 正面**，不要混用俯拍和平拍
- 背景：透明，不要白底、阴影、文字、水印
- 命名：按下面表格的“建议文件名”，全部小写 + 连字符
- 存放：`src/assets/items/`

import qfImg from '@/assets/items/comp-breaker-qf.png'

const imgs = {}
function loadImg(key, src) {
  const img = new Image()
  img.src = src
  imgs[key] = img
}

// 货架格子：图片 + 下方小字，文字保留方便识别
if (imgs.qf?.complete) {
  c.drawImage(imgs.qf, x + 8, y + 4, 70, 32)
  c.fillText('断路器', x + 43, y + 49)
}
